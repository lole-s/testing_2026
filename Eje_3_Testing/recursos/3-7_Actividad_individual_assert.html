Trabajá sin ejecutar el código. En la segunda columna escribí el valor que obtiene el lado izquierdo de ==. Después decidí si coincide con el valor esperado. Cuando un assert falla, Python se detiene.

jugador = "Luna"          monedas = 7          vidas = 2
nivel = 3                 inventario = ["llave", "mapa", "pocion"]

puntaje = monedas * 10 + nivel * 5

assert jugador == "Luna"
assert puntaje == 85
assert monedas + vidas * nivel == 13
assert len(inventario) + vidas == 5
assert puntaje - monedas * 10 == 10
assert nivel * vidas == 6

print("Todas las comprobaciones pasaron")

Recordatorio sobre assert  ·  assert condición, "mensaje opcional"
Comprueba que una condición que debería ser verdadera se cumpla durante la ejecución. La condición puede ser cualquier expresión cuyo resultado sea True o False. Si es True, el programa continúa sin mostrar nada. Si es False, se produce AssertionError, se muestra el mensaje opcional y esa ejecución se detiene.
