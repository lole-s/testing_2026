# 1-10 Repositorio colaborativo desde Visual Studio Code

## Clase: conocer un repositorio y crear el primer Pull Request

## Objetivo

Retomar la cuenta de GitHub creada en la clase anterior y hacer una primera experiencia de trabajo colaborativo con VS Code, Git y GitHub.

En esta clase los grupos van a:

- conocer el repositorio `simon-proa-2026`
- abrir y probar la app Simon
- organizarse en roles de 3 integrantes
- crear una rama de trabajo
- hacer una modificacion pequena
- subir la rama a GitHub
- crear un Pull Request

Flujo de trabajo:

```text
clonar -> explorar -> probar -> crear rama -> modificar -> commit -> push -> Pull Request
```

La recuperacion de la rama desde otra computadora queda para la clase siguiente.

Repositorio:

## Ideas que deben quedar claras

Una rama permite trabajar sin modificar directamente `main`.

Un commit guarda un cambio en el historial local.

Un push sube la rama y los commits a GitHub.

Un Pull Request es una propuesta para revisar cambios antes de incorporarlos a `main`.

Guardar un archivo no alcanza para recuperarlo desde otra computadora. Para eso hace falta commit y push.

---

## Entrega

Cada grupo entrega:

- enlace al Pull Request
- nombre de la rama
- integrantes y roles
- respuestas de la actividad breve
- descripcion del cambio realizado

Preguntas de cierre:

```text
¿Que es una rama?
¿Que es un Pull Request?
¿Por que el cambio no va directo a main?
¿Que diferencia hay entre guardar, commit y push?
```
